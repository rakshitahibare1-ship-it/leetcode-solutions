# Two Sum

**Difficulty:** Easy

**Topic:** Arrays & Strings

**LeetCode:** [Two Sum](https://leetcode.com/problems/two-sum/)

---

## Problem Description

Given an array of integers `nums` and an integer `target`, find two different
indices such that the numbers at those indices add up to the target.

### Example

Input:

```text
nums = [2, 7, 11, 15]
target = 9
